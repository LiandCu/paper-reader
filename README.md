# 拾论文 · Local Paper Reader

Windows 本地论文摘要阅读助手：获取 Hugging Face Daily Papers 榜单，使用可选的 DeepSeek API 生成中文翻译、固定分类和简短讲解。程序及资料保存在项目目录，不下载论文 PDF、不运行论文附带代码，也不在本机加载大模型。

## 功能

- 点击「获取论文」，按已勾选的类型检查 **今天、昨天和前天** 的日榜，以及 **本周和本月** 的榜单。日榜每期保存前 **10 篇**，周榜和月榜每期前 **20 篇**，不足则全部保存。缺失的榜单会跳过。
- 开启晚间自动补做后，默认于 **北京时间 20:00** 检查同一范围。当日手动获取和解读均已完成时跳过。只获取了摘要时，按 AI 设置补解读。错过设定时间，可在当天较晚登录或打开程序时补做。
- 可选「获取后自动翻译与简介」。手动获取后自动解读一批，最多 20 篇。晚间检查范围内尚待解读的摘要，受每日请求上限和任务时限约束。也可以手动批量解读或单篇解读。
- 获取和 AI 分别启动、分别停止；无密钥或 AI 失败时保留原摘要，不循环重试。
- 每日 API 请求上限可设为 1～100 次，失败尝试也计数；简介长度可设为 100～1000 字。
- 20 个固定分类、日期 / 关键词 / 处理状态筛选，支持手动调整分类。
- 五档字号、滚动三个月保留、文本资料导出、关闭自动获取、清单式卸载。

## 启动

1. 在 Windows x64 电脑上克隆或下载完整仓库。此项目当前使用目录为 `D:\classproject\game\paper-reader`，建议恢复到该目录，以保持现有说明和界面显示一致。
2. 双击 `打开论文助手.vbs`；若不可用，使用 `打开论文助手.cmd`。
3. 在浏览器中使用本地阅读界面。服务仅监听 `127.0.0.1`，会自动打开带临时会话标识的本地地址。
4. 进入「设置与数据」，保存 DeepSeek API Key，选择模型并按需勾选「获取后自动翻译与简介」，点击「保存 AI 设置」。要在晚上补做，请勾选「启用晚间自动补做」，选好榜单类型和北京时间，然后点击「保存自动获取设置」。

旧版本升级后，如已设过其他时间，在「每日补做时间」选择 20:00，点击「保存自动获取设置」即可更新现有 Windows 计划任务。

仓库附带 Python 的 Windows 嵌入式运行环境，约 22 MB，位于 `runtime/`，不需要另装 Python 或第三方依赖。原始 Python 许可证见 [runtime/LICENSE.txt](runtime/LICENSE.txt)。首次运行生成本地数据库、项目标记和默认配置，默认不启用自动获取和自动解读；本机已有配置不会被覆盖。

本版本主要用于同一台 Windows 电脑恢复及本地使用。计划任务和界面服务使用固定项目标识，不支持在同一账户下同时部署多份并独立开启自动任务。

## AI 与费用

只有启用自动解读或手动发起解读时，才把论文标题和作者摘要发送给 DeepSeek。解读基于摘要，不能代替阅读全文。实际费用由 API 服务商计费，每日上限是请求次数限制。

API Key 使用当前 Windows 用户的数据保护机制加密保存，不会回显；更换 Windows 用户或电脑后需要重新填写。不要将密钥放进源码、截图或提交记录。

## 仓库与本地数据

仓库包含程序、界面、测试、运行环境及不含个人路径的卸载文件清单。以下内容仅留在本机，由 `.gitignore` 排除：

- `config/` 中的密钥、个人配置和项目标记（仅提交 `manifest.json` 文件清单）。
- `data/` 中的论文库、译文、导出、会话标识和任务状态。
- `logs/`、`cache/`、界面截图及本机验收记录。

因此 GitHub 中的源码副本不包含你的论文阅读资料。恢复已有资料需要另行保留本地数据；不要将含密钥、会话标识或论文库的目录手动加入版本控制。

## 验证与卸载

项目内运行：

```powershell
.\runtime\python.exe -B -m unittest discover -s tests
```

行为检查使用模拟网络和 AI，不消耗真实 API 额度，覆盖日期、自动解读、额度、去重、停止、数据保留、Windows 加密和卸载边界。

自动运行通过可关闭的 Windows 普通用户计划任务实现；不安装驱动、系统服务或修改系统 PATH。后台任务完成后退出。关闭全部阅读页面后，界面服务通常在约两分钟内退出。

设置中可停止自动获取，或预览卸载清单后删除程序。卸载保留未登记文件；Git 版本历史 `.git/` 不会被自动删除。详细操作见 [使用说明](使用说明.md)。
